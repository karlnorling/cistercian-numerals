# @cistercian/core

## 0.2.0

### Minor Changes

- 7bee711: Colours and backgrounds take gradients: CSS `linear-gradient()`, `radial-gradient()` and their `repeating-` forms, or a gradient object. `parseGradient` turns a CSS gradient string into the object form. The CLI's `--color` and `--background` accept the same CSS.

## 0.1.0

### Minor Changes

- 0c82b0f: First release: render numbers as Cistercian numerals in SVG (`@cistercian/core`), PNG, JPEG and WebP (`@cistercian/raster`), and from the command line (`@cistercian/cli`).
