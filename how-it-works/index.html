How numbers are drawn

A Cistercian numeral is a vertical stem with one digit in each corner. Units go top right, tens top left, hundreds bottom right and thousands bottom left. The same nine strokes are mirrored into each corner.

Beyond 1 to 9999

Section titled “Beyond 1 to 9999”

The monks wrote 1 to 9999. This library extends the system so every decimal number gets a drawing:

Input Drawn as Rule
0 a bare stem No digits, so no strokes.
12345 1 2345 One glyph per four digits, like base 10000.
10000 1 0 Empty groups are bare stems, so the position is never lost.
12.5 12 · 5000 A dot on the baseline, then the fraction in groups of four.
0.0005 0 · 5 Fraction groups count from the point, so .5 and .0005 differ.
-42 42 with a bar A horizontal bar across the middle of the first stem.

Note

These extensions are modern; the monks didn’t use them. Zero as a bare stem, the negative bar and the glyph proportions follow akosnikhazy/cistercian-numerals.

Floats

Section titled “Floats”

A JavaScript number is first written in its shortest exact form, so 0.1 draws as 0.1. Arithmetic can leave float noise, and that gets drawn too: 0.1 + 0.2 is 0.30000000000000004. Round first, or pass a string or bigint to keep every digit.
