## `toSvg(value, options?)`

Returns an SVG string. `value` can be a `number`, `bigint` or decimal `string`.

```js
import { toSvg } from '@cistercian/core';

toSvg(1993);
toSvg('3.14159', { size: 200, color: '#7a2e0e', background: 'white' });
```

| Option        | Default        | Notes                                                                 |
| ------------- | -------------- | --------------------------------------------------------------------- |
| `size`        | `100`          | Image height in pixels. The width follows from the number of glyphs.  |
| `color`       | `currentColor` | Stroke colour or gradient. `currentColor` takes the text colour.      |
| `background`  | none           | Colour or gradient behind the glyphs.                                 |
| `strokeWidth` | `4`            | In viewBox units, where the stem is 80 long and each corner is 20×20. |
| `linecap`     | `round`        | `round`, `square` or `butt`.                                          |
| `gap`         | `20`           | Space between glyphs, in viewBox units.                               |
| `padding`     | `10`           | Space around the glyphs, in viewBox units.                            |
| `title`       | the number     | Accessible name. `false` leaves it out and sets `aria-hidden`.        |

Throws a `TypeError` for text that isn't a decimal number and a `RangeError` for `NaN`, `Infinity` or a bad option.

## Colours and gradients

`color` and `background` take any CSS colour, or a gradient. Write a gradient the way you would in CSS, or pass an object:

```js
toSvg(123456789, {
  color: 'linear-gradient(to right, #e03131, #f76707, #fab005, #40c057, #228be6, #7048e8, #be4bdb)',
});

toSvg('2026.1225', {
  color: 'repeating-linear-gradient(135deg, #e03131 0 3%, #ffffff 3% 6%)',
  background: 'radial-gradient(#2b8a3e, #0b3d20)',
});

toSvg(1993, {
  color: { type: 'linear', angle: 90, stops: ['#e03131', { color: '#7048e8', offset: 0.8 }] },
});
```

  <Glyph

    strokeWidth={7}

    color="repeating-linear-gradient(135deg, #e03131 0 3%, #ffffff 3% 6%)"
    background="radial-gradient(#2b8a3e, #0b3d20)"
    caption="Christmas"
  />
</div>

- `linear-gradient()` takes an angle (`90deg`, `0.25turn`) or a side (`to right`, `to bottom left`). The default runs top to bottom.
- `radial-gradient()` spreads from the centre out to the corners.
- `repeating-linear-gradient()` and `repeating-radial-gradient()` repeat their stops. Give a stop two positions, as in `red 0 3%`, for a hard-edged band: that's how the candy-cane stripes are made.
- Stop positions are percentages. Stops without one are spaced evenly.
- A gradient spans the whole image, not each glyph, so a long number runs through every colour once.

`parseGradient(css)` turns a CSS gradient string into the object form, and returns `undefined` for a plain colour.

## Lower level

```js
import { format, glyphStrokes, parse } from '@cistercian/core';

parse('-12.5'); // { negative: true, integer: [12], fraction: [5000] }
format(parse('007.100')); // '7.1'
glyphStrokes(1993); // [[[0, 0], [0, 4]], [[0, 0], [1, 1]], ...]
```

`glyphStrokes(n, { negative? })` returns polylines for one glyph from 0 to 9999. The stem runs from `(0, 0)` to `(0, 4)` and each corner is 1×1. Use it to draw on a canvas, in a PDF or anywhere else.
