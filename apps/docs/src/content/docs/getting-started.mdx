import { Tabs, TabItem } from '@astrojs/starlight/components';

Pick the package for where you render:

| Package                                                       | Use it for                                                                |
| ------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [`@cistercian/core`](/cistercian-numerals/packages/core/)     | SVG strings in any JavaScript runtime, browser included. No dependencies. |
| [`@cistercian/raster`](/cistercian-numerals/packages/raster/) | PNG, JPEG or WebP in Node. Uses sharp.                                    |
| [`@cistercian/cli`](/cistercian-numerals/packages/cli/)       | Files from the terminal or scripts.                                       |

## SVG

<Tabs syncKey="pm">
  <TabItem label="npm">

```sh
npm install @cistercian/core
```

  </TabItem>
  <TabItem label="yarn">

```sh
yarn add @cistercian/core
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm add @cistercian/core
```

  </TabItem>
</Tabs>

```js
import { toSvg } from '@cistercian/core';

document.querySelector('#year').innerHTML = toSvg(new Date().getFullYear(), { size: 120 });
```

The SVG uses `currentColor` by default, so it takes the colour of the text around it.

## Images

```sh
npm install @cistercian/raster
```

```js
import { toImage } from '@cistercian/raster';
import { writeFile } from 'node:fs/promises';

await writeFile('1993.webp', await toImage(1993, { format: 'webp', size: 400 }));
```

## Command line

```sh
npx @cistercian/cli 1993 -o 1993.png --size 200
```

Not sure what a number will look like? Try it in the [playground](/cistercian-numerals/playground/).
